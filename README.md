# Md. Maruf Hossen — Portfolio

Personal portfolio of **Md. Maruf Hossen**, B.Sc. EEE student at Jamalpur Science & Technology University, Bangladesh.

> Status: v1 built from the available content. Remaining work and owner inputs are tracked in [IMPLEMENTATION.md](IMPLEMENTATION.md#current-status).

## Features (target)

- Sections: Home, About & Education, Skills & Achievements, Projects & Research, Hobbies, Contact
- Downloadable CV from the home section (`cv.pdf` in the repository root)
- Dark / light theme with system preference and persistence
- Project and skill filtering (Web, Hardware, Analysis)
- Smooth, reduced-motion-aware scroll animations
- Responsive from 320 px to large desktop
- Working contact form (Formspree)
- SEO: Open Graph/Twitter cards, JSON-LD, sitemap, custom favicon
- Lighthouse ≥ 95, WCAG 2.2 AA, no trackers or third-party scripts

## Tech

HTML5 · CSS3 (design tokens) · vanilla JavaScript (ES modules) · GitHub Pages. No framework, no build step.

## Run locally

```bash
npm run dev        # http://localhost:3000
npm run check      # lint, format, link and content checks
```
